# 型C ワーク型（7日間プログラム形式）

「読む」より「変わる」を売る型。行動の悩み（先延ばし・習慣・話し方の練習系）、
「何をすればいいか」が明確に段階化できるテーマに使う。

## 章構成（目標 42,000〜52,000字）

| 章 | 役割 | 字数配分 |
|---|---|---|
| はじめに | 共感→「7日後のあなた」の約束→プログラムの使い方 | 3,000〜3,500 |
| 序章 | なぜ7日で変わるのか（構造の説明＋命名フレームワーク）＋開始前チェック | 4,500〜5,500 |
| DAY1〜DAY7 | 1日1章。下記「1日の型」に従う | 各 4,000〜5,500 |
| 終章 | 8日目からの続け方（縮小版ルーティン）＋つまずいた人への再スタート手順 | 3,500〜4,500 |
| おわりに＋巻末 | back_matter.md に従う | 2,500〜3,000 |

## 1日（1章）の型

1. **今日のゴール**: 1行。「今日は◯◯ができれば合格」
2. **なぜ今日これをやるのか**: 昨日との接続（2〜3段落）
3. **ワーク本体**: 所要時間・道具・手順を明記。書き込み欄を想定した
   問いを3〜5個（Kindleでは書き込めないため「スマホのメモに書く」前提で設計）
4. **具体例**: 記入例を必ず2人分（うまくいった例・つまずいた例）。著者資産を使う
5. **つまずきポイント**: 「できなかった日」の扱い方を必ず書く（脱落防止）
6. **今日のひとこと**: 同伴の声で締める

## 冒頭1000字の書き出しパターン

- 挫折の記憶から入る: 「三日坊主という言葉に、何度刺されてきただろう。」
- 「頑張らない宣言」から入る: 「このプログラムに、根性は要らない。
  むしろ根性で乗り切ろうとした瞬間に失敗する。」

## 締めの型

終章は「7日やり切れなかった人」を必ず救済する（読了率と星に直結）。
「DAY3で止まった人は、DAY3からでなくDAY2の縮小版から」など再開手順を具体化。

## NG事項

- ワークが精神論（「自分を褒めましょう」だけ等、記入例が書けないワーク）
- 1日の負荷が不均等（DAY1が5分でDAY4が2時間）
- 記入例なしのワーク（読者は白紙の問いには答えられない）
- 「毎日続けることが大事です」という説教で埋める
