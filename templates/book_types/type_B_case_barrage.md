# 型B ケース連発型（Q&A・事例50連発）

拾い読み耐性が高い。悩みの裾野が広いテーマ、「自分のケースはどれ?」と
探しながら読むテーマに使う。KENP（読了ページ課金）と相性が良い。

## 章構成（目標 42,000〜60,000字）

| 部 | 役割 | 字数配分 |
|---|---|---|
| はじめに | 共感→「この中にあなたの場面が必ずある」宣言→使い方（どこから読んでもいい） | 2,500〜3,000 |
| 序章 | 全ケースを貫く著者の視点＝命名フレームワークを1つ提示（3,000字） | 3,000〜4,000 |
| 第1部〜第5部 | 場面別にケースを 8〜12 本ずつ、計 40〜55 本 | 各 6,500〜9,000 |
| 終章 | ケースを横断して見える構造＋今夜の一歩 | 3,000〜4,000 |
| おわりに＋巻末 | back_matter.md に従う | 2,500〜3,000 |

## 1ケースの型（650〜900字で固定。粒度を揃えることが命）

1. **見出し**: 読者の言葉のQ（「既読スルーが3日続いています」）
2. **場面**: 状況を3〜4行で具体的に（誰が・いつ・何を言った/した）
3. **どう考えるか**: 序章のフレームワークをこのケースに適用（断言する）
4. **どう動くか**: 台本 or 手順（そのまま使える形）
5. **ひとこと**: 著者の同伴の声1〜2行

## 冒頭1000字の書き出しパターン

- 「相談の多さ」から入る: 「この10年で、同じ相談を何度受けたか分からない。
  言葉は違っても、困りごとの芯はいつも同じ場所にあった。」
- 目次の価値を前倒しで見せる: 代表的なQを5個並べて「全部この本の中にある」。

## 締めの型

終章で「50ケースに通底する1つの構造」に着地させる。バラバラの事例集で
終わらせない（これがAI量産型Q&A集との差になる）。

## NG事項

- ケースの長さがバラバラ（300字のケースと2000字のケースが混在）
- 回答が一般論（「気にしすぎないようにしましょう」）
- 同じ回答の使い回し（構造が同じでも、台本・場面は必ず変える）
- ケース数の水増しのために悩みを不自然に細分化する
