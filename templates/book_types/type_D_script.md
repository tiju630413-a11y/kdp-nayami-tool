# 型D セリフ台本型（場面別「こう言えばいい」実例集）

『言い返せないあなたへ』の型を昇華・一般化したもの。
「その場で言葉が出ない」系の悩み（言い返せない・断れない・雑談・依頼・謝罪）に使う。
検索意図が「例文・フレーズ」の読者を最短で満足させる型。

## 章構成（目標 42,000〜55,000字）

| 章 | 役割 | 字数配分 |
|---|---|---|
| はじめに | 共感→「明日から口に出せる台本◯本」の約束（本数を明記）→使い方 | 3,000〜3,500 |
| 第1章 原理 | なぜ言葉が出ないのか＋台本の使い方の原理（命名フレームワーク）。丸暗記でなく「型」で持つ | 5,000〜6,500 |
| 第2章〜第6章 | 場面別台本集。1章=1場面群、1章に台本6〜10本 | 各 6,000〜8,000 |
| 終章 | 台本が効かなかったときの撤退線（逃げる・距離を取る判断基準） | 3,500〜4,500 |
| おわりに＋巻末 | back_matter.md に従う | 2,500〜3,000 |

台本の総本数は 30〜45 本。**はじめにで約束した本数と実数を必ず一致させる**
（review_checklist 3-2）。

## 1台本の型（600〜900字）

1. **場面**: 相手の台詞から始める。「『これ、今日中にできるよね?』——金曜の17時に」
2. **言えなかった記憶**: そのとき飲み込んだ言葉・体の感覚（同伴の声）
3. **台本**: そのまま口に出せる一言〜三言。**言い方（トーン・間・視線）まで指定**
4. **なぜこれが効くのか**: 第1章の原理との接続（2〜3段落）
5. **バリエーション**: 相手が食い下がってきた場合の二の手
6. **NG例**: やりがちな返し方と、それがなぜ悪化を招くか

## 冒頭1000字の書き出しパターン

- 飲み込んだ言葉から入る: 「あのとき言えなかった言葉を、私は帰りの電車で
  100回くらい頭の中で言い直した。」
- 台本の効能の反転から入る: 「気の利いた返しは要らない。必要なのは、
  自分を守る最低限の一言だけだ。」

## 締めの型

終章は必ず「言葉で解決しない相手・状況」の見極めを書く。
台本万能論で終わらせない（誠実さがレビューを守る）。

## NG事項

- 台本が長い（3文超の反撃スピーチは現場で使えない）
- 相手を打ち負かす台本（読者が求めるのは勝利でなく安全）
- 言い方の指定がない（文字面だけでは再現できない）
- 場面設定が曖昧（「嫌なことを言われたら」ではなく「会議で頭ごなしに否定されたら」）
