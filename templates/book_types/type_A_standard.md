# 型A 標準型（共感 → 構造分解 → 対処法 → ケーススタディ → 明日の一歩）

悩み系の基本形。初めて扱うテーマ、構造の説明が価値になるテーマに使う。

## 章構成（目標 42,000〜55,000字）

| 章 | 役割 | 字数配分 |
|---|---|---|
| はじめに | 無料サンプル勝負。共感→読後の変化の約束→目次の価値提示 | 2,500〜3,500 |
| 第1章 共感 | 「あなたの夜」を描く。読者の場面を3〜5個、当事者の言葉で再現 | 5,000〜6,000 |
| 第2章 構造分解 | なぜそうなるか。悪循環の図解＋命名フレームワークの導入 | 6,000〜8,000 |
| 第3章 対処法（考え方） | 構造を断つ視点の転換。断言をここに置く | 6,000〜8,000 |
| 第4章 対処法（行動） | 具体的な手順・台本。再現できる粒度まで分解 | 7,000〜9,000 |
| 第5章 ケーススタディ | 著者資産ベースの実例4〜6本。Before→After | 8,000〜10,000 |
| 第6章 明日の一歩 | 最小の実行装置（チェックリスト/7日メニューの短縮版） | 4,000〜5,000 |
| おわりに＋巻末 | back_matter.md に従う | 2,500〜3,500 |

字数配分の考え方: 後半（4〜5章）を厚くする。前半に理屈を積みすぎると
「説明ばかりで実践がない」レビューを生む。1章あたりの上限は10,000字
（超えたら分割）。

## 冒頭1000字の書き出しパターン

1. 場面から入る（推奨）: 読者の「あの瞬間」を二人称または一人称で再現。
   「日曜の夜、明日の朝礼を思い出して、テレビの音が急に遠くなる——」
2. 台詞から入る: 現場で聞いた一言を冒頭に置く。「『そんなことも
   できないの?』——この一言を、私は10年経ったいまも覚えている。」
3. 反転宣言から入る: 常識の否定を最初の3行で。「言い返せないのは、
   気が弱いからではない。私はそう断言する。」

いずれも「この本を読み終えたとき、あなたは◯◯できるようになっている」
という読後の変化の約束を1000字以内に必ず含める。

## 締めの型

- 最終章は要約でなく「今夜の一歩」1つ＋「1週間後のあなた」の描写で締める。
- おわりには著者の一人称で、本を書いた理由（体験）に戻って閉じる。

## NG事項

- 第2章（構造）が本の半分を占める（理屈太り）
- ケーススタディが創作臭い（著者資産に基づかない架空例の連発）
- 「まとめ」章を作る
- 対処法が「意識を変える」系で終わる（再現粒度不足）
