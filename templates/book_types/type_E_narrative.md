# 型E 一人称ナラティブ型（体験談ベース）

note で確立済みの「痛みの可視化・常識の反転・一人称」戦略の書籍転用。
著者資産が最も厚いテーマ、当事者性そのものが価値になるテーマに使う。
5つの型の中で最もAI代替されにくいが、最も著者資産を消費する
（1冊で資産15〜20件目安。plan 工程は資産残量を確認してからこの型を選ぶこと）。

## 章構成（目標 40,000〜50,000字）

| 章 | 役割 | 字数配分 |
|---|---|---|
| はじめに | 「これは私の記録だ」宣言＋読者への約束（あなたの話でもある） | 2,500〜3,000 |
| 第1章 底 | いちばん苦しかった時期の具体的な描写。日付・場面・台詞 | 6,000〜7,500 |
| 第2章 もがき | 試して失敗したことを正直に並べる（一般論への反証がここに宿る） | 6,500〜8,000 |
| 第3章 転機 | 変わり始めたきっかけ。劇的にしない（正直さが命） | 6,000〜7,500 |
| 第4章 反転 | 体験から得た持論＝常識の反転を、断言として言語化（命名フレームワーク） | 6,500〜8,000 |
| 第5章 手渡し | 同じ場所にいる読者へ、体験を再現可能な形に翻訳（実行装置） | 7,000〜8,500 |
| おわりに＋巻末 | いまの地点から。back_matter.md に従う | 3,000〜3,500 |

## 冒頭1000字の書き出しパターン

- 最も鮮明な一場面から入る（時系列の説明をしない）:
  「◯年◯月、私は会社のトイレの個室で、昼休みが終わるのを待っていた。」
- 現在から過去へ: 「いまなら分かる。あのとき私に必要だったのは、
  努力ではなかった。」

## 締めの型

- 「治った・解決した」で終わらせない。「いまも◯◯な日はある。それでも」の
  地点で閉じる（読者は完治譚より併走者を信頼する）。

## ナラティブ固有の規則

- 時系列の嘘をつかない。脚色は「場面の圧縮・仮名化・細部のぼかし」まで。
  なかった出来事の創作は禁止（著者資産にない場面を書かない）
- 登場人物は仮名＋属性ぼかしで匿名化（review_checklist 9-2）
- 第5章の「翻訳」を必ず入れる。体験談だけで終わると「あなたの話であって
  私の役には立たない」レビューを生む
- 医療（不調・通院）に触れる場合は診断名の自己判断を書かず、
  専門家誘導定型文を挿入（guide.md §3.3）

## NG事項

- 武勇伝化（気づけば成功譚のトーンになっている）
- 一般論による埋め草（体験が薄い章を「世間では〜」で埋める）
- 読者への説教への転化（「だからあなたも〜すべき」）
- 他者（元上司・家族等）への断罪が目的化した章
