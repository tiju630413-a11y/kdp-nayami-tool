# 工程5: style_pass — 文体仕上げ（prompts/05_style.md）

review_loop 収束後の最終磨き。style_check.py の全項目 PASS まで仕上げる。
ここでの仕事は「直し」であって「書き直し」ではない。内容・構成には触れない
（内容の問題が見つかったら review_loop に差し戻す）。

## 手順

### 1. 機械チェック

```bash
cat books/NNN_*/draft/ch*.md > books/NNN_*/_work/manuscript_combined.md
python3 scripts/style_check.py books/NNN_*/_work/manuscript_combined.md
```

### 2. FAIL の解消（機械が示した箇所のみ）

- **NG表現**: 削除または言い換え。言い換えの際、同じNGリストの別表現に
  置き換えない（「まとめると」→「要するに」は不可）。多くの場合、
  その一文ごと削るのが正解
- **文末連続**: 語順の入れ替え・体言止め（頻度上限内）・「〜のだ」変換で散らす。
  意味を変えない
- **具体性不足の章**: これは内容の問題。review_loop へ差し戻し
  （style_pass で例を捏造して埋めない）
- **診断的表現**: 断定を外し、必要なら guide.md §3.3 の定型文を挿入

### 3. WARN の判断

- 読点密度・段落長の WARN は音読して判断（機械の目安より耳を優先）。
  直さない判断をした WARN は理由を1行記録
- 誤字系 WARN は全て解消

### 3.5 日本語三軸パス（`japanese_quality_prompt.md` 基準）

style_check.py が拾えない漢字水準・誤用を、三軸で通す（自然さ＝軸3の一部は
機械が拾うが、残りはここで）:
- 軸1 漢字水準: この本の漢字上限（book.json の genre。実用書＝準2級／小説＝2級）を
  超える難読・硬い漢字を、ひらがなに開くかルビを振る。開き漏れを拾う
- 軸2 誤用: ら抜き・さ入れ、主述のねじれ、二重敬語、慣用句の誤用、重言、表記ゆれ
- 軸3 自然さ: 同長文の3連続、段落頭の接続詞連発、同一語尾4連続、AI常套句
- 直しは意図・雰囲気を壊さない範囲にとどめる。要修正が構成・内容に及ぶなら
  review_loop（jp_quality 観点）へ差し戻す

### 4. 音読パス（機械で拾えない最終確認）

冒頭1000字・各章の冒頭段落・おわりに、を音読想定で通す:
- つっかえる箇所 → 語順か読点を直す
- 同じ言葉が近くで2回鳴る → 片方を言い換え
- 声が変わって聞こえる章 → その章の冒頭3段落を前章の声で書き直す

### 5. 完了条件

- style_check の verdict が **PASS**（FAILゼロ）
- 修正ログを `books/NNN_*/_work/style_pass_log.md` に残す
  （FAIL何件→何をしたか、残したWARNと理由）

## 章単位で draft/ を更新すること

結合ファイル（manuscript_combined.md）を直接編集しない。修正は必ず
draft/ch*.md 側に施し、再結合して再チェックする（結合ファイルは使い捨て）。
