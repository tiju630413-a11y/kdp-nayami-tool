# 工程8: promo — 販促パック生成（prompts/08_promo.md）

1冊につき: Amazon紹介文1本＋note記事2本＋X投稿5本。
文体は本文と同じ style/guide.md（媒体で声を変えない）。

## 入力

1. `books/NNN_*/draft/` — 完成原稿（切り出し・抜粋の原本）
2. `books/NNN_*/plan.md` — 読者・断言・命名FW・実行装置の実数
3. `templates/description.md` / `templates/note_article.md` / `templates/x_posts.md`
4. `data/genre_map.json` — 該当エントリの pain / keywords

## 手順

### 1. Amazon 紹介文（templates/description.md の型で）

- 冒頭3行に全力（痛みの言葉→同伴→変化の約束）
- **固有の武器を数字と名前で**: 実行装置の実数（台本N本等）は draft を
  数えて確定させる（plan の予定数でなく実数。ここがズレると
  review_checklist 3-2 違反になる）
- 命名フレームワークの名前を必ず入れる
- 完成後、テンプレート末尾のNGチェック5項目を自己適用。
  「一般論の要約に読める」場合は書き直し（判定に迷ったら、書いた紹介文から
  タイトルと固有名詞を伏せて読み、他の本でも通用するなら不合格）

### 2. note 記事2本（templates/note_article.md の型で）

- 記事1（本文切り出し型): 単体で完結して読める・共感最強の節を選ぶ。
  台本・ワークの核心は出しすぎない
- 記事2（執筆後記型): 本文未使用の著者資産があればそれを起点にする
- 既存2シリーズ（職場の人間関係・30代リーダー論)への相互リンク位置を指定

### 3. X 投稿5本（templates/x_posts.md の型で）

- 役割固定: 発売告知1 / 共感フック2 / 本文抜粋1 / レビューお願い1
- 共感フック2本は**本の宣伝をしない**（リンクなし・言語化だけで完結）
- 抜粋は命名FWか台本から（一般論に読める箇所を選ばない）
- 各投稿に投稿タイミング（発売日+N日・時間帯）を付す

## 出力

```
books/NNN_*/promo/
├── description.md   # 紹介文（KDP画面貼り付け用の完成形＋HTMLタグなし）
├── note_1.md        # 切り出し記事（公開日: 発売日）
├── note_2.md        # 後記記事（公開日: 発売日+3〜4日）
└── x_posts.md       # 5本＋投稿スケジュール表
```

## 自己チェック

- [ ] 紹介文の数字（台本N本等）が draft の実数と一致
- [ ] レビュー依頼に特典・見返りの文言がない（規約）
- [ ] note 記事にも ng_phrases が混入していない
      （python3 scripts/style_check.py で各ファイルを --min-chars 1 で検査）
- [ ] X 5本すべて140字以内（リンク除く）

## 追補: KDP登録シートとSNS戦略（v3.2）

### KDP登録シート（工程7で自動生成）
promo後、`python3 scripts/kdp_sheet.py NNN` で全項目版シートを生成する。
そのために book.json（フリガナ・ローマ字・英題・版数・著者読み・成人向け等）と
kdp_meta.json（キーワード7＋根拠・カテゴリ3の日英）を埋めること。定義は
templates/kdp_sheet.md。

### SNS戦略（無名スタート前提）
著者が無名（フォロワー少）の間は、告知中心の x_posts.md ではなく
**共感で拡散・価値で信頼**の設計にする。1冊ごとに
`books/NNN/promo/sns_strategy.md` を作り、次を含める:
- プロフィール（名前・bio・固定ポスト）の設定文
- 共感フック（リンクなし・拡散用）とミニ台本の無料放出（価値・保存用）を各3本以上
- 発売スレッド（末尾だけリンク）
- 投稿カレンダー（発売2週間前から夜に継続）
- note: 価値を出しきる完結記事＋本への軟導線。発売前に1本置くと入口が強い
- やらないこと（相互フォロー・特典レビュー依頼＝規約違反 等）
すべて X は140字以内・ng_phrases なしを style_check で確認する。
フォロワーが増えたら通常の告知比重（templates/x_posts.md の役割配分）へ移行してよい。
