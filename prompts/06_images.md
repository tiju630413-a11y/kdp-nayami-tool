# 工程6: images — 挿絵・図解・表紙プロンプト生成（prompts/06_images.md）

画像の生成そのものは**ユーザーが Gemini で実行**する。この工程の仕事は
「コピペで使える Gemini プロンプト＋挿入位置＋代替テキスト」の一式を作ること。

## 入力

1. `books/NNN_*/draft/` — 完成原稿（各章の内容から図解対象を選ぶ）
2. `cover/visual_system.md` — グリッド・カテゴリ別パレット・プロンプト雛形
3. `books/NNN_*/plan.md` — カテゴリ（帯色決定）・シリーズ名・巻数

## 手順

### 1. 表紙（1点＋予備1点）

- visual_system.md の表紙雛形を使い、この本の「読者の孤独な場面」を
  キービジュアルとして指定する（本文の冒頭場面から取るのが基本）
- カテゴリの帯色HEXを雛形に埋める
- 予備案は場面違いでもう1本（Geminiの出力が弱かったとき用）
- タイトル文字入れの指定を添える: 帯位置・行割り・フォントの方向性
  （太ゴシック系）・シリーズ番号表記

### 2. 本文挿絵・図解（各章1点目安）

章ごとに3系統（構造図 / 対処フロー / Before→After）から適切なものを選ぶ:
- その章の**いちばん誤読されやすい説明**を図解対象にする（飾りの絵を作らない）
- 構造図・フローは、ノード数・矢印の向き・ループか直線かをプロンプトで固定
- ラベル文字は後入れなので、「どのノードに何の文字を入れるか」の
  ラベル表を必ず添える

### 3. 出力（books/NNN_*/images/image_spec.md）

```markdown
# 画像仕様書: {タイトル}

## 運用手順（ユーザー向け）
1. 下の各プロンプトを Gemini に貼って生成（1点につき2〜4枚出して選ぶ）
2. 採用画像を books/NNN_*/images/ に保存（ファイル名は指定どおり）
3. 表紙: タイトル文字をラベル表どおりに重ねる（Canva等）
4. 縮小視認テスト（下記）→ OKなら build へ

## 表紙
- ファイル名: cover.jpg（1600x2560）
- Gemini プロンプト: {雛形に場面・帯色を埋めた完成形}
- 文字入れ指定: {帯位置 / 1行目「…」2行目「…」 / シリーズ表記 / 著者名}
- 縮小視認テスト: python3 -c "from PIL import Image; ..."（90px縮小）
  → visual_system.md §4 の5項目を目視確認

## 第1章: {章タイトル}
- ファイル名: ch01.jpg / 挿入位置: {節見出しの直後 等、draft の行が特定できる指定}
- 系統: {構造図 等} / Gemini プロンプト: {完成形}
- ラベル表: {ノード1=「引き金」…}
- 代替テキスト: {スクリーンリーダー・画像非表示環境向けの一文}

（全章分）
```

### 4. 自己チェック

- [ ] 全プロンプトに no text, no letters 系のネガティブ指定がある
- [ ] 帯色がカテゴリパレットと一致
- [ ] 挿入位置が draft の実在の見出し・段落を指している
- [ ] 代替テキストが「画像の説明」でなく「図が伝える内容」になっている
- [ ] 点数が過剰でない（各章1点目安。EPUB 3MB 目安を超えそうなら減らす）
