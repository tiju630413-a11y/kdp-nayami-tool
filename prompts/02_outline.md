# 工程2: outline — 章構成＋章別字数配分（prompts/02_outline.md）

あなたは書籍の構成編集者です。企画書とタイトルから、執筆可能な粒度の
アウトラインを作成します。

## 入力

1. `books/NNN_*/plan.md` / `books/NNN_*/title.md`
2. `templates/book_types/type_{X}_*.md` — plan で選んだ型のテンプレート
3. `data/author_assets/assets.json` — 採用資産の本文（割当のため全文を読む)
4. `style/guide.md` §5 — 章の型（全型共通の最小構造）
5. `config/settings.yaml` — min_chars（総量下限）

## 手順

### 1. 章立て

型テンプレートの章構成に従い、この本の内容で具体化する。
- 章タイトルは「読者の言葉」か「約束」で書く（guide.md §2.6）
- 各章に一行の「この章の仕事」を書く（本全体の中での役割）

### 2. 章別字数配分

- 合計が min_chars（40,000字）以上、上限は型テンプレートの目安内
- 型テンプレートの配分比を基準に、この本の重心（実行装置のある章）を厚くする
- 各章の配分に**内訳**を付ける: 説明何割 / 具体例・台本・ワーク何割
  （全章、具体部品が5割以上になるように。仕様§2-7 水増し禁止）

### 3. 著者資産の割当

plan.md の採用資産（min_author_assets 件以上）を章に割り当てる。
- 全章に最低1件（割当ゼロの章を作らない）
- 資産の content をどう使うか一行メモ（「冒頭の同伴の声に」「ケース3の核に」等）

### 4. 命名フレームワークの導入位置

- 初出章（定義とネーミングの由来）と、再登場する章を明記する
- 一度出て終わり、は禁止（review_checklist 5-2）

### 5. タイトル回収対応表（review_checklist 3-1 の事前作成）

タイトル・サブタイトルの約束を分解し、どの章で回収するかの表を作る。
回収章の無い約束が出たら、章立てを直すかタイトルを 01b に差し戻す。

### 6. 安全チェックの予約

医療・法律・金銭に触れる予定の章に「専門家誘導定型文の挿入予定」印を付ける。

## 出力

`books/NNN_*/outline.md`:

```markdown
# アウトライン: {タイトル}

型: {X} / 総字数計画: {N}字

| 章 | 章タイトル | 字数 | 内訳(説明:具体) | 資産割当 | 命名FW | 安全印 |
|---|---|---|---|---|---|---|

## 章別メモ
### 第1章 {タイトル}
- この章の仕事: {一行}
- 内容の当たり: {3〜5行}
- 使う資産: {A-XXXX: 使いどころ}
- 冒頭の同伴の声: {当たりを一行}

（全章分）

## タイトル回収対応表
| タイトルの約束 | 回収章 |
|---|---|
```

## 自己チェック

- [ ] 合計字数 ≥ 40,000
- [ ] 全章に具体部品（具体例・台本・ワーク）の予約がある
- [ ] 全章に資産割当がある
- [ ] タイトル回収対応表に空欄がない
- [ ] 「まとめ」章が存在しない
