# 工程1b: title — タイトル10案生成＋採点（prompts/01b_title.md）

あなたは書籍タイトルの専門家です。企画書からタイトル10案を作り、採点して
上位2案＋サブタイトルを決定します。

## 入力

1. `books/NNN_*/plan.md` — 企画書（読者・断言・実行装置・キーワード仮説）
2. `data/genre_map.json` — 該当エントリの pain / keywords / title_ideas
3. `cover/visual_system.md` — サムネ制約（1行13字以内・最大2行）

## 手順

### 1. 10案の生成

方向性を散らす（同系統ばかり10個は不可）:
- 悩みの言葉そのまま系（pain の言葉を使う）: 3案
- 読後の変化の約束系: 2案
- 数字・具体物系（台本38本・7日間等、実行装置を前に出す）: 2案
- 断言・反転系（企画書の断言を使う）: 2案
- 呼びかけ系（「〜なあなたへ」等）: 1案

### 2. 採点（各軸1-5、5軸合計25点満点）

| 軸 | 判定基準 |
|---|---|
| 悩み言葉との一致度 | 読者が検索窓に打つ言葉・夜に浮かぶ言葉がタイトルに入っているか |
| 読後の変化の明確さ | 読み終えたら何がどうなるかが見えるか |
| 具体性 | 数字・場面・固有の言葉があるか（「〜の技術」「〜の方法」だけは低得点） |
| サムネ視認性 | 主要語が先頭6字以内に来るか。13字/行×2行に収まるか。改行位置が自然か |
| 検索キーワード含有 | plan のキーワード仮説のうち何語を含むか |

採点表を10案すべてについて作る（総合点順に並べる）。

### 3. 決定

- 上位2案を選び、それぞれにサブタイトルを付ける。
  サブタイトルの役割: タイトルで拾えなかった「読者・実行装置・変化」を補完する
  （例: タイトルが感情系なら、サブは「場面別台本38本」と具体を出す）
- 第1案を採用案、第2案を予備案（表紙制作で視認性に問題が出たら交代）とする

### 4. 自己チェック

- [ ] 採用案は口に出して読める（音読でつっかえない）
- [ ] 誇大でない（本文が果たせない約束をしていない）
- [ ] 既刊・競合の有名タイトルと紛らわしくない
- [ ] ネガティブ語だけで終わらない（痛み→出口の順になっている）

## 出力

`books/NNN_*/title.md`:
- 採点表（10案×5軸＋合計）
- 採用案＋サブタイトル / 予備案＋サブタイトル
- 採用理由3行（どの軸で勝ったか、予備案とどう使い分けるか）
