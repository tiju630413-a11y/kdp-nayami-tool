# 文体ガイド＋執筆姿勢（style/guide.md）

このガイドは全工程（draft / review_loop / style_pass / promo）で参照する。
守れない箇所は style_check.py が機械検出し、機械で拾えない部分は
review_loop の「文体番人」観点が判定する。
人間の通読で修正が出たら、原因を必ずこのファイルか ng_phrases.txt か
review_checklist.md に還流する（一発OK還流ルール）。

---

## 1. 執筆姿勢（何を書くかの前に、どう向き合うか）

### 1.1 読者を責めない
- 「できないあなたが悪い」「甘えです」「意識が低い」系の表現は全面禁止。
- 読者は深夜にひとりで検索してこの本に辿り着いた人。まず「その状態のまま
  ここまで来たこと」を肯定してから、次の一歩を差し出す。
- 叱咤激励で動く読者はこの本を買わない。動けなさの構造を一緒に見る側に立つ。

### 1.2 初心者に寄り添う
- 専門用語は初出で必ず言い換える。
  例: 「認知の歪み——つまり、事実よりも悪いほうに解釈してしまう頭のクセ」
- 抽象1に対して具体2。抽象的な主張を書いたら、その場で具体例を2つ置く。
- 手順は「今夜、布団の中でもできる」粒度まで分解する。
  ×「まず自己分析をしましょう」
  ○「スマホのメモ帳を開いて、今日いちばん嫌だった瞬間を一行だけ書く」

### 1.3 具体的・詳細・丁寧
- 場面が目に浮かぶ描写。時間帯・場所・相手の言葉・体の感覚を入れる。
  ×「上司に叱られてつらい」
  ○「月曜の朝礼、みんなの前で『これ、やり直しね』と言われた瞬間、
    耳が熱くなって、そのあとの連絡事項が何も頭に入らなかった」
- 数字と固有の状況を使う。「多くの人」より「私が研修で会った200人のうち、
  手を挙げたのは3人だった」。
- 迷ったら「たとえば」で地に足をつける。

### 1.4 同伴の声（全型共通）
- 各章の冒頭と章間ブリッジに、一人称の実感・体験を短く置く。
  情報の前に「分かってもらえた」を先に渡す。
- 上から教えない。「私もここで何度も転んだ」の位置から書く。

## 2. 文体規則（機械チェック対象）

### 2.1 句読点
- 読点間隔は 9〜11 字を目安とする（7字未満で細切れ、14字超で息切れ）。
- 読点を打ちすぎない。迷ったら音読し、息継ぎの位置にだけ打つ。

### 2.2 文末バリエーション
- 同一文末（「〜ます。〜ます。」「〜だ。〜だ。」等）の連続は 2 回まで。
- 「です・ます」基調。ただし独白・回想・断言の一文は「だ・である」や
  体言止めを混ぜてよい（リズムのための転調として意図的に使う）。

### 2.3 体言止め
- 体言止めは1節（見出し区切り）につき 2 回まで。連発すると広告文になる。

### 2.4 段落
- 1段落は 400 字以内。スマホの画面で「壁」に見えたら長すぎる。
- 1段落1メッセージ。話が変わったら改行ではなく段落を変える。

### 2.5 箇条書き
- 箇条書きは1章に 3 ブロックまで。本文で語れることを箇条書きに逃げない。
- 手順・チェックリスト・台本の列挙のみ許可。感情や主張は必ず地の文で書く。

### 2.6 見出し
- 見出しは「読者の言葉」か「約束」で書く。
  ×「コミュニケーションの重要性」
  ○「なぜ、あの人には言い返せないのか」「明日の朝、これだけやってみる」
- 見出しだけ拾い読みしても本の流れが分かる状態にする。

## 3. 禁止事項

### 3.1 AI常套句（ng_phrases.txt に列挙、機械検出）
「〜ではないでしょうか」「いかがでしたか」「まとめると」等。
検出されたら言い換えではなく「その文が本当に必要か」から考え直す。

### 3.2 水増しの禁止
- 同じ主張の言い換えで字数を稼がない。4万字は具体例・台本・ワーク・
  ケースの「追加」で達成する。
- 「先ほども述べたように」が2回出たら構成を疑う。

### 3.3 断定してはいけない領域（医療・法律・金銭）
- 診断的表現の禁止: 「あなたは〜障害かもしれません」「それは〜病です」
- 法律・金銭の断定禁止: 「必ず勝てます」「絶対に儲かります」「〜すべきです（法的判断）」
- これらの領域に触れる章には、専門家誘導の定型文を必ず挿入する:
  - メンタル: 「つらさが2週間以上続く、日常生活に支障が出ている——そんなときは、
    ひとりで抱えず、心療内科や公的な相談窓口など専門家の力を借りてください。
    本書は医療の代わりにはなれません。」
  - 法律: 「個別の事情で結論が変わる領域です。実際に動く前に、法テラスや
    自治体の無料法律相談など、専門家に確認してください。」
  - 金銭: 「本書は特定の金融商品を勧めるものではありません。大きなお金を
    動かす前に、公的な相談窓口や専門家の意見を確認してください。」

### 3.4 断定していい領域（むしろ義務）
- 著者の立場・持論・経験則は、逃げずに断言する。「〜かもしれません」で
  ぼかした持論は読者に届かない。両論併記で終わる章は書き直し。
- 断言の責任は「私はこう考える」「私の場合はこうだった」の一人称で取る。

## 4. リズムの作り方（音読基準）

- 書き終えた節は一度「声に出して読める速さ」を想像して読み返す。
  つっかえる場所は読点か語順の問題。
- 長文→短文→短文、のリズムを意識する。重要な一文ほど短く。
- 漢字の連続は4文字まで（熟語を除く）。ひらがなを開いて呼吸を作る。
  例: 「事前確認実施後」→「事前の確認をすませたあと」

## 5. 章の型（全型共通の最小構造）

1. 冒頭: 同伴の声（一人称の場面・実感）で入る。一般論から入らない。
2. 中盤: 構造の説明は具体例2つ以上とセットで。
3. 必須部品: 各章に「具体例・台本・ワーク」のいずれか1つ以上。
4. 締め: 「今夜できる一歩」か「次章への橋」で終える。要約で終えない
  （「まとめ」節は原則作らない。まとめないと伝わらない章は書き直す）。
