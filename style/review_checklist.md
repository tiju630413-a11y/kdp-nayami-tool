# 星1レビュー逆算チェックリスト（style/review_checklist.md）

低評価レビューの典型理由を先回りで潰す。review_loop の
「辛口Amazonレビュアー」観点はこの全項目を原稿に適用し、
1項目でも FAIL があれば重大指摘として改稿に回す。
実際に低評価が付いたら、その理由をこのリストに新項目として追加する（還流）。

判定は各項目 PASS / FAIL / N/A。FAIL には該当箇所（章・節）を必ず添える。

---

## 1.「内容が薄い」対策

- [ ] **1-1 具体部品の実数**: 全章に「具体例・台本・ワーク」が1つ以上ある。
      本全体で具体例・ケース・台本の合計が 30 個以上ある（数える）。
- [ ] **1-2 水増し検出**: 同じ主張の言い換えだけの節が存在しない。
      各章を1行要約したとき、要約が重複する章のペアがない。
- [ ] **1-3 4万字の内訳**: 総字数の過半が「具体例・台本・ワーク・ケース・体験」
      で構成されている（説明・一般論が過半なら FAIL）。

## 2.「AIっぽい」対策

- [ ] **2-1 style_check PASS**: ng_phrases 検出ゼロ、文末重複・読点密度・
      段落長が基準内。
- [ ] **2-2 声の一貫性**: 冒頭・中盤・終盤から各1節を抜き出して読み比べ、
      同じ人が書いた声に聞こえる。
- [ ] **2-3 一人称の実在感**: 著者自身の体験・観察が全章に最低1箇所ある
      （著者資産の採用箇所を数える）。

## 3.「タイトルと中身が違う」対策

- [ ] **3-1 タイトル回収対応表**: タイトル・サブタイトルの約束（読後の変化）が
      本文のどの章で回収されるか、対応表を作って全て埋まる。
      回収章が示せない約束が1つでもあれば FAIL。
- [ ] **3-2 紹介文との整合**: Amazon紹介文で提示した数字・部品
      （「台本40本」等）が本文に実在し、数が合っている。
- [ ] **3-3 想定読者のズレ**: 「はじめに」で宣言した読者像と、本文の事例の
      主語がずれていない（読者が20代会社員なのに事例が全部経営者、等）。

## 4.「実践できない」対策

- [ ] **4-1 再現粒度**: 全てのワーク・手順が「道具・所要時間・最初の一手」
      まで書いてある。「意識を変えましょう」型の手順が残っていたら FAIL。
- [ ] **4-2 今夜の一歩**: 各章の締めに、その夜のうちにできる行動が1つある。
- [ ] **4-3 実行装置の搭載**: 台本・チェックリスト・7日プログラム等、
      「読み終えた直後に手が動く」部品が本全体で1系統以上、完結した形である。

## 5.「どこかで読んだ話ばかり」対策

- [ ] **5-1 著者資産の採用数**: min_author_assets（既定10）件以上を採用し、
      どの章で使ったか一覧できる。
- [ ] **5-2 命名フレームワーク**: 本書オリジナルの名前付きメソッド・概念が
      1つ以上あり、章をまたいで機能している（一度出て終わりなら FAIL）。
- [ ] **5-3 断言の存在**: 「常識の反転」にあたる著者の立場表明が明確に1つ以上
      あり、本の背骨になっている。両論併記で終わる章があれば FAIL。

## 6.「AIに聞けば済む」対策（AI代替判定）

- [ ] **6-1 ベースライン比較**: books/NNN/baseline.md（素のプロンプトで実生成した
      AI回答）と章ごとに比較し、固有事例・断言・命名・実行装置の4面で
      上回らない章がゼロ。上回らない章は著者資産を追加注入して改稿。
- [ ] **6-2 引用可能性**: この本にしかない言葉（命名・断言・台詞）を3つ挙げられる。
      挙げられなければ FAIL。

## 7.「誤字脱字」対策

- [ ] **7-1 機械パス**: style_check の誤字パス（重複助詞・変換ミスパターン）で
      検出ゼロ。
- [ ] **7-2 固有名詞・数字**: 本文中の数字（「3つの方法」等）と実際の個数が
      一致する。章番号・図番号の参照切れがない。

## 8.「説教くさい」対策

- [ ] **8-1 命令形の密度**: 「〜しましょう」「〜すべき」が1章に3回以下。
- [ ] **8-2 読者を責める表現**: 「できないのは〜だから」型の帰責表現がゼロ。
- [ ] **8-3 同伴の声**: 章冒頭が一般論・説教でなく、場面・実感で始まっている。

## 9. 安全・規約（該当時のみ）

- [ ] **9-1 医療・法律・金銭**: 断定表現がなく、該当章に専門家誘導定型文が
      挿入済み（style/guide.md §3.3 の定型）。
- [ ] **9-2 実話の匿名化**: 登場する実話・台詞が個人を特定できない形に
      加工されている。
